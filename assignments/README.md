# Assignment seeds

These files are ready-to-copy bodies for GitHub Issues. For each session:

1. Open the matching file.
2. Copy its content into a new Issue using the **System design lesson** template.
3. Assign the Issue to the learner.
4. Add it to the Project board.
5. Link the Issue from the pull request and evidence.

GitHub does not automatically create Issues from files in a repository, so this step is intentionally manual.
